This War of Mine ภาษาไทย — PWA

สำคัญ: การเปิด index.html จากไฟล์ในโทรศัพท์ (file://) จะไม่ติดตั้งเป็น PWA และไม่เปิด Service Worker ต้องนำโฟลเดอร์นี้ขึ้นโฮสต์ HTTPS ก่อน

วิธีง่าย: GitHub Pages
1. สร้าง GitHub repository ใหม่ (Public)
2. อัปโหลด index.html, sw.js, manifest.webmanifest และโฟลเดอร์ icons โดยรักษาโครงสร้างเดิม
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save
4. รอให้ได้ URL https://ชื่อผู้ใช้.github.io/ชื่อ-repository/
5. เปิด URL นี้ใน Chrome บน Android > เมนู ⋮ > Install app หรือ Add to Home screen
6. เปิดไอคอนจากหน้าจอมือถือได้โดยตรง หลังโหลดครั้งแรกไฟล์หลักจะถูกแคชเพื่อเปิดแบบออฟไลน์

ข้อควรทราบ:
- GitHub Pages แบบ Public เปิดเผยไฟล์และเนื้อเรื่องต่อสาธารณะ ถ้าไม่ต้องการเผยแพร่ให้ใช้โฮสต์ HTTPS แบบส่วนตัวที่รองรับ PWA แทน
- เนื้อเรื่องและข้อมูลที่บันทึกใน localStorage อยู่กับ origin/โดเมนเดิม ไม่ย้ายจาก file:// หรือโดเมนอื่นอัตโนมัติ ให้ส่งออกเซฟจากเว็บเก่าก่อนแล้วนำเข้าในเว็บใหม่
- เสียง AI ออนไลน์ต้องมีเซิร์ฟเวอร์ /tts ที่เปิดใช้งานและการตั้งค่า API ของตัวเอง; โฮสต์ไฟล์ PWA อย่างเดียวไม่ทำให้เสียง AI ใช้ได้
- OCR ในเบราว์เซอร์และเสียงอ่านระบบอาจแตกต่างกันตามอุปกรณ์
- การอัปเดตเว็บไซต์: เปลี่ยนชื่อ CACHE ใน sw.js เป็น v2, v3 ... แล้วอัปโหลดใหม่
